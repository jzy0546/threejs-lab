# Three.js Lab Product Marketing Context

## Site

- Name: Three.js Lab
- Production URL: `https://threejs.vavist.com`
- Type: static browser tool site for Three.js/WebGL builders
- Audience: Three.js developers, WebGL builders, product viewer builders, technical designers
- Goal: get visitors to use a focused tool, copy code, and move to the next related tool

## SEO Positioning

Own utility and example queries where the user wants a working browser tool or copyable code:

- `online glb viewer`
- `three js glb viewer`
- `three js camera fov calculator`
- `three js shader material starter`
- `three js lighting presets`
- `three js examples with code`
- `three js fit camera to object`
- `three js gltfloader example`
- `three js particles example`

Do not compete with the Vavist root site for long editorial guide queries unless the page contains a real interactive tool or example.

## Page Quality Rule

Every page should include:

- One precise H1.
- Unique title and description.
- Self-referencing canonical.
- Valid JSON-LD.
- Static explanatory copy that remains useful if WebGL fails.
- At least two related internal links.
- A clear tool, example, code block, FAQ, or workflow.
