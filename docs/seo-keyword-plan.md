## Page Template for Future Long-Tail Pages

Each new page should include:

- One clear H1 matching a long-tail search query.
- A live preview or working tool above the fold.
- A short explanation of when to use the pattern.
- A copyable code block.
- A parameter table or controls.
- Three FAQ items using user search language.
- Internal links to two related tools.
